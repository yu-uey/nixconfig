# NixOS Config

I used NixOS as my daily driver from 2022~2025, on an iMac desktop and later a MS Surface Laptop. This repository gathers my scattered configs and merges them into one repository.

Because I rewrote my configuration at some point, the iMac and Surface configs come from separate git histories. The commit author dates are not in chronological order because of the cherry-picking that was done to combine their files. I also rebased to remove a secret from an early point in history, hence the commit dates.
